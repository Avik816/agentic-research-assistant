## Files Description:

| File | Description | Returns |
|------|-------------|---------|
| **`api_main.py`** | This is the file that creates and configures the Fast API application.<br><br>**The responsibilities are:**<br>- Create the FastAPI application.<br>- Register middleware.<br>- Register API routers.<br>- Mount static files.<br>- Register startup/shutdown events. | FastAPI application: Configured FastAPI application. |
| **`health.py`** | Used to verify that the backend API is running or not. | JSON message verifying the status of the backend API. |
| **`request.py`** | Defines the schema for the incoming user request, including the user query and session identifier.<br><br>**The responsibilities are:**<br>- Check whether the data received via the API has the proper schema or not. | Request schema used for validating incoming API requests. |
| **`response.py`** | Defines the schema for the response returned by the backend, including the responder agent's output and the corresponding session identifier.<br><br>**The responsibilities are:**<br>- Check whether the data returned via the API has the proper schema or not. | Response schema used for validating outgoing API responses. |
| **`chat_service.py`** | This file handles the applications chat workflow. It is the central service layer responsible for handling all chat requests received from the API. It acts as the coordination layer between the backend API and the AI engine.The service itself does not contain decision-making or AI logic.It manages the overall chat workflow by invoking the Planner Agent, passing the necessary request and session information, and returning the generated response back to the API.<br><br>**The responsibilities are:**<br>- Receives validated chat requests from the API.<br>- Extracts request and session information.<br>- Invokes the Planner Agent to determine the required execution workflow.<br>- Returns the final response generated by the engine to the API layer.<br>- Maintains separation between the API layer and the internal engine components. | A ChatResponse object containing:<br>    - success (bool): Indicates whether the request was processed successfully.<br>    - session_id (str): The session identifier associated with the conversation.<br>    - response (str): The final response generated by the AI engine (currently a placeholder during implementation). |
